# Campus Sports Game Registration App

Ready-to-deploy Vercel application featuring specific sports slot limits (Volleyball 32, Basketball 12, Egg Game 30, Save the Water 30, 3-1 Game 32), auto team splitter, direct mobile QR code scanning, and organizer session controls.

## 🚀 How to Deploy on Vercel

1. **Extract this zip file** on your computer or phone.
2. Push all files to a new repository on **GitHub**.
3. Go to **[Vercel.com](https://vercel.com)**, sign in with GitHub, and click **Add New > Project**.
4. Import your repository and tap **Deploy**.
5. Once live, open your Vercel URL (e.g. `https://your-app.vercel.app`) to start managing registrations!
